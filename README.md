# 2. 🍎 Nutrition Education AI

### Description
**Nutrition Education AI** is an intelligent chatbot that provides general educational information about nutrition and healthy eating. It can explain food groups, vitamins, minerals, hydration, balanced diets, healthy snacks, meal planning, food labels, and general fitness nutrition. It supports **English, Tamil, and Thanglish**, making nutrition information easier to understand.
